Command line

The CLI tools are in the kiesei image, with the same host name and kubeconfig as the driver. Open a shell in it from the repository: bash driver/kiesei.sh shell. The HTTP tools use this same host; kubectl and bao keep their own endpoints (the kubeconfig in the run directory; the store's port on the driver's machine).

# Argo CD CLI, through the portal (in the kiesei shell)
argocd login HOST --grpc-web-root-path argocd --username admin

# the admin password, until sign-on
kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath='{.data.password}' | base64 -d

# the cluster
export KUBECONFIG=var/run/ENV/current/kubeconfig
kubectl get applications -n argocd

# the cluster secret store (local: OpenBao beside the cluster)
BAO_ADDR=http://127.0.0.1:8200 bao status

Replace HOST with this page's host name and ENV with the environment's name.
